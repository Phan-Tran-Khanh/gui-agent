\begin{abstract}
Mobile GUIs are not designed for automation, and current multi-modal large language models (MLLMs) often hallucinate actions when control is based on free-form coordinates or ungrounded text. We study a screenshot-only mobile agent that treats the MLLM as a decision engine while grounding each action in detected UI elements. The system decomposes user goals into sub-goals, compiles a GUI state from visual parsing (element indices and bounding boxes) plus linguistic context, and executes atomic actions by mapping selected elements to device coordinates. A reflection stage detects stalled interactions, verifies progress, and triggers replanning. We provide an end-to-end implementation with a sequential executor, event streaming, and observability tooling, designed for device-integrated evaluation. 

This paper focuses on the architecture, grounding mechanism, and engineering tradeoffs rather than model training.
