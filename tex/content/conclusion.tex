\section{Conclusions and Future Work}
\label{conclusion}

We presented a screenshot-only mobile GUI agent that treats the MLLM as a decision engine while grounding each action in detected UI elements. The pipeline combines planning, grounded action selection, execution on device, and reflection, and it provides a practical implementation with event streaming and observability to support analysis and iterative development. Our focus is architectural and engineering-oriented, emphasizing reproducible grounding and clear interfaces rather than claims of new model capability.

Future work will concentrate on validating and extending the system. Key directions include (i) quantitative evaluation across diverse mobile tasks with strong baselines and ablations, (ii) robust reflection mechanisms such as stall detection and screen-question answering, (iii) improved visual focus via masking and cropping, (iv) composite skills and long-term memory for reuse and efficiency, and (v) failure analysis to characterize detector gaps and recovery strategies. \textcolor{red}{TODO: add results-driven conclusions once experiments are completed.}
